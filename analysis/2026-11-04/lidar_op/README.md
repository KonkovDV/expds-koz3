# Рабочая точка курганов на лидаре: есть ли запас в порогах (04.11.2026)

**Вопрос** (из задания к 0,61, пункт «пороги курганов лидара»). Лидар — 33 % эталонов публичного теста и почти весь вес
курганов (30 + 20 из 100). Во всех четырёх посылках лидар одинаков: P/R .516/.504. Ни одна посылка не проверяла
другую рабочую точку. Даёт ли сдвиг порогов курганов лидара рост?

Расчёт описательный, не гейт: изменение не предлагается, PREREG не нужен.

## Данные и способ

**Входы.**
- Стек A гейта honest-10: `stack_arch.geojson` (sha256 `b412e299…`), `table.pkl` (sha256 `e01823a5…`).
- Эталон `gt_train_v2.geojson`.
- Бокс восстановлен скриптом `scripts/box_restore.sh`.

**Пороги.** Честные, по фолдам семей: 10 фолдов, `d3_gate.honest`. A honest = 0,314615 — совпадает с прежними прогонами.

**Что меняется.** Пороги курганов (`kurgany_povrezhdennye`, `kurgany_tselye`) всех групп `li*` умножаются на s. Остальные классы и группы не трогаются.

**Метрика — как у организаторов.** FP идёт с весом 0,5: P = TP/(TP + 0,5·FP), R = TP/эталоны, F1 = 2PR/(P+R)
(`materials/compute_metrics.py:696`, `expds/metric.py:960`). Площадка печатает P по типам данных той же формулой
(`compute_metrics.py:1071`).

**Как считаются P и R.** TP/FP — по прогнозам групп `li*`. R ≈ TP групп `li*`, делённое на эталоны с `markup_type = li`. Таких эталонов 2449:

| Класс | Эталонов |
|---|---|
| повреждённые курганы | 1371 |
| целые курганы | 783 |
| фортификации | 264 |
| городища | 30 |
| архитектура | 1 |

Сопоставление в метрике общее по классу, поэтому R — приближение.

**Файлы.** Скрипт `li_op.py`, результат `li_op.json`.

## Результат

| s | 0,8 | 0,9 | **1,0** | 1,1 |
|---|---|---|---|---|
| TP / FP (li*) | 1267 / 3578 | 1232 / 3116 | 1169 / 2417 | 1104 / 2122 |
| OOF P / R | .415 / .517 | .442 / .503 | **.492 / .477** | .510 / .451 |
| OOF F1 | .460 | .470 | **.484** | .479 |
| перенос на тест: P×1,050, R×1,056 | .436 / .546 | .464 / .531 | **.516 / .504** | .536 / .476 |
| F1 лидара на тесте (перенос) | .485 | .495 | **.510** | .504 |

Перенос откалиброван по s = 1,0: при нём он даёт ровно P/R площадки. Коэффициенты 1,05 по P и 1,06 по R означают, что
честный OOF почти без сдвига переносится на публичный тест.

## Вывод

1. Пороги v2 (s = 1,0) — максимум F1 и в OOF, и в переносе на тест. Обе стороны от максимума хуже:
   - при снижении порогов (1,0 → 0,9) добавляется 63 TP ценой 699 FP;
   - при повышении (1,0 → 1,1) теряется 65 TP ради снятия 295 FP.
2. Сдвиг порогов курганов лидара — не рычаг. LB-пробу на него не тратить. Лидар растёт только от лучшего
   ранжирования, то есть от лучшей карты или модели, а не от порога.
3. Оговорка. Перенос пропорциональный: коэффициент один на всю кривую. Если на тесте низкоуверенные объекты точнее,
   чем на трейне, оптимум сдвигается. Но кривая плоская (±0,006 F1 на ±10 % порога), так что выигрыш был бы мал и в
   этом случае.
