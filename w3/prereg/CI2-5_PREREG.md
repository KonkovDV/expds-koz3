# CI2-5 PREREG — W3, 30.10 14:20 MSK (до любых измерений)
Идея (REVIEW_SOTA CI2-5): адаптивный кроп по размеру объекта для gor/крупных без лидара.
Реализация (box CPU, без GPU и без новых растров):
- Растры Or/SpOr есть только в S3; на box их нет, S3-ключи не используем.
- Поэтому берём готовые эмбеддинги W5 DINOv2-S (read-only). Их кроп уже адаптивный: half = max(16 м, 1.25·max(w,h)).
- Обучение головы верификатора: LR LOFO по site_family, отдельно для каждого класса.
Скоуп: кандидаты split_arch, markup_type≠li, классы gorodishcha / fortifikatsii / arkhitektury / object_poly (~18.8k). Лидарные кандидаты не меняются.
Признаки: logit(conf), log(площадь, м²), log(аспект), PCA-32 эмбеддинга. PCA обучается только на train-фолде.
Метка: центроид кандидата внутри GT того же класса и региона.
Варианты (заданы заранее, без подбора):
- C5A: conf := p_LR для всех кандидатов в скоупе.
- C5B: C5A только для кандидатов с площадью ≥ 2000 м²; остальные без изменений.
- C5C: conf := 0.5·conf + 0.5·p_LR.
Gate: w3_gate honest-10, Δ ≥ +0.003, P(A>B) ≥ 0.9, без падения на 34new и optical. A = 0.314615.
Ограничение заранее: gor на Ae (19 GT) и Or (4 GT) не имеют gor-кандидатов. Перескоринг их recall не поднимает; размерный бин 5–10 тыс. м² решается только новым детектором (GPU-ветка CI2-5 на acc1 остаётся).
