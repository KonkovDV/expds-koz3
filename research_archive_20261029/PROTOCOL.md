# Протокол фабрики ботов KOZ3 (обязателен для ботов 2–8)

1. Задача = контракт. В reports/botN_<тема>.md сверху: цель, гипотеза, критерий приёмки (метрика и порог Δ), бюджет (часы GPU/CPU), ветка. Без критерия заявку на ресурс не беру.
2. Один владелец. Один бот на задачу, ветка bots/botN-*, свой worktree /workspace/koz3-wt/botN-*. В main пишет только Дмитрий через PR. WIP: не больше 1 активной задачи и 2 заявок на ресурсы на бота.
3. Аренда ресурсов. Задача на ресурсе = файл leases/<полоса>_<job>.lease (кто, что, старт, ожидаемый конец, heartbeat). Нет heartbeat дольше 2× ожидаемого шага — «1» считает задачу зависшей и перезапускает или снимает.
4. Возобновляемость. Любая задача длиннее 10 мин: чекпоинты, идемпотентный перезапуск, STATUS.txt (RUNNING/DONE/FAILED + время), логи рядом. ПК отключается, поэтому без этого на ПК не ставлю.
5. Ворота качества (по порядку): тесты (box/run_tests.sh) → e2e на mock → honest-10 (и по слою) → сравнение с базой v2 0,3125 mock / LB 0,41238. Новое по умолчанию OFF. Принято только при Δ>0 без провала любого слоя > 0,01.
6. Реестр экспериментов. Каждый результат — строка в EXPERIMENTS.csv (sha, метрики, вердикт). Отрицательный результат тоже пишем.
7. Воспроизводимость. Веса и zip — с sha256; конфиг и seed в отчёте; правила docs/RULES.md (без Yandex/Google/Bing/Esri, без данных КОЗ №2, лицензии весов).
8. Связь. Отчёт «1» короткий: что сделано, цифры, следующий шаг, нужен ли ресурс. Блокер — сразу, с priority. Без «готово», пока ворота не пройдены.
9. Без простоя. Закончил — берёшь свой следующий пункт из BACKLOG.md и сообщаешь «1».
