## Валидность результатов
1. STATUS "DONE" ≠ успех. Проверять exit code == 0 (обёртки .bat/.ps1 пишут DONE даже при ошибке).
2. Время работы должно быть правдоподобным: полный e2e-инференс ~15 мин. Прогон за секунды = INVALID. geojson, «подобранный» при exit≠0 или с mtime раньше старта контейнера, = INVALID (случай A4 bot2 29.10: 28 с, exit -1).
3. Проверять main.log на WARNING/ERROR: «pixgbm включён, но expds/geo_pixgbm.py нет» (откат на классику, случай bot6 r1) и pixgbm «ступени {}» (модуль загружен, но ни одной ступени не выполнил = no-op, случай base v2).
4. Δ ровно 0 между ON и OFF значит, что фича не сработала. Сначала выяснить почему, и только потом называть её нейтральной (gor_dense: max conf 0.228 < τ 0.824).
5. Проверка соответствия делается на zip сабмита, а не на kit-zip.
6. Перед запуском проверять, что файлы весов непустые (size>0 + torch.load). Случай 29.10: 0-байтный li_gor_mask_r18.pt от robocopy /XC /XN /XO; нужно /IS /IT.

## PIXGBM
7. expds/geo_pixgbm.py в .gitignore по правилу владельца (docs/PIXGBM_DECISION.md). НЕ коммитить и не просить коммитить. В чистый worktree внедрять с проверкой sha. На ПК EXPDS_PIXGBM_STRICT=1.
8. Чистый worktree без models/pixgbm/all/poly.txt роняет тесты: тесты не должны зависеть от этого файла.

## ПК (Windows, PowerShell 5)
9. Запускать только через schtasks: процессы из сессии умирают при обрыве связи. У отработавших разовых задач не должно быть будущих триггеров.
10. .ps1 только в ASCII, вместо кириллического пути использовать $env:USERPROFILE. Никакого `python -c` с двойными кавычками (PS5 их съедает), только .py-файл.
11. Связь рвётся (spawn EPERM / unreachable), а ПК при этом включён. Повторять с паузами и ставить только возобновляемые задачи.
12. CopyFromBox/CopyToBox: ≤100 MiB на файл, корень — домашняя папка пользователя. Веса передавать частями по 20 МБ + SHA256SUMS, собирать и сверять sha на ПК.
13. Диск: F: почти полон, на него ничего нового не писать. JobDir и worktree держать на C:\Sloi\pc_jobs. Свои wt_* удалять после синхронизации результатов. C:\Sloi\TRASH и чужие docker-контейнеры не трогать.
14. GPU одна: задачи строго по очереди, gate-прогоны только в Docker pantum/n7q:20261024.
