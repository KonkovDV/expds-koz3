# Декларация об использовании ИИ-инструментов (черновик)

Требование: п. 8.5.3 и 13.6 проекта ТР КОЗ №3. Нужно указать **все** средства, применённые за весь период разработки: наименование, версию, разработчика, этапы применения и решаемые задачи. При расхождении с фактическим кодом возможна защита решения. Код, который команда не может объяснить, использовать нельзя (п. 13.6.3).

Перед подачей сверьтесь с официальным шаблоном `ai-declaration.md` с платформы.

## Правила ведения

1. Запись — в день использования. Указывайте конкретные файлы и функции.
2. Каждый сгенерированный фрагмент должен прочитать член команды и записать себя в последнюю колонку.
3. Отдельно отмечайте фрагменты, переписанные вручную: это помогает на защите.
4. Если используется бот «Слои» или другие ассистенты — они тоже в журнал.
