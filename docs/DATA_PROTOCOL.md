# Протокол обращения с конкурсными данными

Основание: п. 13.11 проекта ТР КОЗ №3 и ответы организаторов на вопросы.

1. **Где лежат данные.** Только на персональных устройствах членов команды, используемых для разработки. В репозиторий, Docker-образ, архив решения и мессенджеры данные и производные (тайлы, отмывки, эталон, кэши) не попадают. Это обеспечивают `.gitignore` и проверка в `scripts/build_submission.py`.
2. **Ключи доступа (S3).** Храните только локально (переменные окружения, `.env` вне git). Не публикуйте и не пересылайте.
3. **Облако (Kaggle, Colab, аренда GPU).** Только при необходимости и с выполнением условий организаторов:
   - доступ только у уполномоченных членов команды;
   - защита от копирования;
   - учёт временных копий;
   - своевременное удаление.

   Конкретно это значит: приватные наборы, журнал копий ниже, удаление всех версий после конкурса. До начала работы — письменный ответ организаторов, что меры достаточны. Запись в разборе от 15.10.2026, что зарубежные площадки уже разрешены, таким ответом не является: в переписке организаторов это «не может считаться автоматически разрешённым».
4. **Третьи лица.** Друзьям и компьютерам вне команды данные не передаются.
5. **Удаление.** Все копии удаляются в течение 14 дней после публикации протокола о завершении КОЗ №3 (п. 13.11.4). Факт удаления фиксируется в журнале.
