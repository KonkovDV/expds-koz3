## 1. Общая информация
- Название команды: StrataTrace
- Название решения: expds-koz3 — позднее слияние детекторов по типам данных (лидар из LAS, спутник, аэрофото, геофизика) с записью в GeoJSON EPSG:3857

## 2б. Линия PIXGBM: замена EN-производного кода чистой переписью
- Прежняя пиксельная модель геофизики (`expds/geo_pixgbm.py`, модели `models/pixgbm/*`, ветки `bots/bot3-*`) происходит из линии, связанной с внешним кодом (EN). Решение Елены 29.10.2026: линия переписывается.
- Новая реализация `expds/pix_clean.py` (+ `expds/pix_org.py`, `expds/pix_org_et.py`) написана **по спецификации** `docs/PIXGBM_SPEC_CLEANROOM.md` (автор спецификации ≠ исполнитель): исполнитель (Grok Bot, бот 5 / W4) не открывал EN-файлы, старые модели и их историю; журнал прочитанного — `orch/bot-W4/CLEANROOM_READLOG.md`. Включается только `geophys.pixgbm.impl = "clean"` за флагом (по умолчанию выключено).
- DOC-1: в `configs/default.toml` `[geophys.pixgbm] enabled = false` явно; `scripts/build_submission.py` не кладёт `geo_pixgbm.py` / `geo_finds_gbm.py` и после сборки вызывает `scripts/check_archive_clean.py`, который роняет сборку, если в архиве есть `geo_pixgbm.py`, `geo_finds_gbm.py`, `models/pixgbm/*`, `analysis/*` или конфиг с включённым legacy PIXGBM.

Полный перечень библиотек и весов — [`docs/THIRD_PARTY.md`](THIRD_PARTY.md). Построчный журнал (дата, задача, затронутые файлы) — [`docs/AI_DECLARATION.md`](AI_DECLARATION.md).
