## Что сделано с помощью этих средств и что решает человек

Код инференса, тесты и документы в git команда может открыть и объяснить. Журнал привязывает день к файлам. Порог, флаг и публичный балл в конфиг и в `docs/LB_LOG.md` попадают после измерения, не из текста модели.

12.11 средства использовались дважды. Сначала — разбор пути сдачи: битая мозаика и умершее чтение окна больше не стирают уже найденные объекты (`docs/AUDIT_2026-11-12.md`). Затем — пакет документов: живые README и архитектура отделены от журналов своей даты (`docs/DOCS.md`). Пороги не двигались.
