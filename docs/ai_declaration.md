## 3. Линия PIXGBM: замена EN-производного кода чистой переписью

* Прежняя пиксельная модель геофизики (`expds/geo_pixgbm.py`, модели `models/pixgbm/*`, ветки `bots/bot3-*`) происходит
  из линии, связанной с внешним кодом (EN). Решение Елены 29.10: линия переписывается.
* Новая реализация `expds/pix_clean.py` (+ `expds/pix_org.py`) написана **по спецификации** `docs/PIXGBM_SPEC_CLEANROOM.md`
  (автор спецификации ≠ исполнитель): исполнитель (Grok Bot, бот 5 / W4) не открывал EN-файлы, старые модели и их историю;
  журнал прочитанного — `orch/bot-W4/CLEANROOM_READLOG.md`. Флаг по умолчанию выключен (`geophys.pixgbm.impl="clean"`).
* В архив «надёжный» v2-clean не входят `geo_pixgbm.py`, `models/pixgbm/*` из v2 и копии `analysis/`; проверка — список
  файлов и сверка путей при сборке.
