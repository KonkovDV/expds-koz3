Источник истины — утверждённый ТР: `docs/background/TR_KOZ3_approved.pdf` (текст — `TR_KOZ3_approved.txt`, номера строк ниже — по нему)
и ответы организаторов на консультации №2 (`docs/background/KOZ3_consult2_answers.txt`). Отличия от проекта ТР —
`docs/background/TR_DIFF_draft_vs_approved.md`. Сверка кода — `docs/COMPLIANCE_2026-10-29.md`. Обновлено 29.10.2026.

## Вход (Прил. 1, п. 4 — стр. 1704–1734)

- Валидация содержит LAS (`La`, markup `li`), Ae, SpOr, Or, MagGr, EtGr, TerFl (.tif). **Хилшейдов `Li` и разметки на валидации нет.**
  Любой лидарный признак строится только из LAS. Разметка Li на трейне сделана по хилшейдам из LAS алгоритмом бейзлайна.
- Названия регионов на валидации анонимизированы — нельзя завязываться на имена/семьи участков.
- LAS и Li совпадают по охвату и привязке.

## Выход (Прил. 1 п. 3 — стр. 1645–1700; Прил. 3 — стр. 1895–1915)

- Один GeoJSON FeatureCollection, EPSG:3857 (градусы не поддерживаются), geometry — Polygon.
- `class_name` — один из 7 классов. Неизвестный класс **пропускается**, файл не отклоняется (новое в утв. ТР).
- Необязательно: `region_name` (иначе `default_source`), `markup_type` (li, ae, sp_or, or, maggr, etgr, terfl), `confidence` (иначе 1.0; задаёт порядок жадного матчинга).
- **Отклонение файла:** > 100 МБ; > 20 000 объектов; > 50 замечаний валидатора геометрии на весь файл.
  Замечание — одно нарушение на объект/точку: незамкнутое кольцо; кольцо > 3000 точек; самопересечение/невалидность;
  площадь ≤ 0 или > 1e12 м²; координата вне ±1e8, NaN/Inf; пара (0,0); больше 15 знаков после запятой.
  Отдельный дефект объекта сам по себе файл не отклоняет (объект исправляется или пропускается).
- Код держит: ≤ 3000 вершин, ≤ 20 000 объектов, ≤ 97 МБ, 2 знака координат, отбрасывание невалидных после округления
  (`expds/writer.py`); `expds.writer.validate` и `scripts/check_submission.py` считают замечания и падают при > 50.

## Метрика (Прил. 4 — стр. 1966+; `materials/compute_metrics.py`)

Взвешенный F1: повреждённые курганы 30, целые 20, городища 15, архитектура 10, object_poly 10, finds_points 10, фортификации 5.
Precision = TP/(TP + 0.5·FP + ε), Recall = TP/(TP + FN + ε), ε = 1e-6. Полигон: покрытие ≥ 0.5 меньшей фигуры и rep(P) внутри эталона;
точки — ≤ 2 м. Матчинг по классу по всей территории, по убыванию confidence. Нормировка — на классы, присутствующие в GT (решение 08.10,
реализовано в официальном скрипте). Дедупликация — **внутри типа данных** (markup_type); между типами не склеивать: объект, размеченный
на лидаре и на снимке, — два эталона. Электроразведка: каждая карта — отдельные объекты.

## Платформа (Прил. 2, Прил. 3, п. 3.4, 7.x)

- Архив .zip ≤ 2 ГБ: только код, конфиги, веса. Выборки в архив нельзя (3.4). Точка входа — из `metadata.json` (`entry_point`), имя файла любое
  (в утв. ТР папка `inference/` больше не обязательна; у нас `python inference/main.py`).
- `metadata.json`: публичный образ Docker Hub + команда запуска. Без интернета (стр. 1858), запись только в выделенную директорию, 30 мин на прогон (п. 7.10, стр. 801–802).
  Со страницы материалов платформы (не из ТР): 96 ГБ RAM, 24 ядра, `/dev/shm` 16 ГБ, ≤ 8192 процессов вместе с потоками, RTX 4090.
- Предупреждение в коде: сторож времени `expds/watchdog.py` (лимит 1800 с, `PLATFORM_LIMIT_S`).

## Лицензии и сторонние результаты (12.3, 12.5, 13.4, 13.5)

- 12.3: соблюдать открытые лицензии (авторство, уведомления, исходники, производные). 12.5: лицензии не должны мешать передаче прав на ПКК Оператору.
- 13.4: нельзя закрытые библиотеки с недетерминированным поведением и любые лицензии, ограничивающие некоммерческое использование.
  Разрешены NVIDIA Driver, CUDA Runtime/Toolkit, cuDNN — указать компоненты и версии, драйвер в ПКК не включать (консультация №2).
- AGPL-3.0 (ultralytics) не запрещён сам по себе, но архитектура проверяется (12.3/12.5). У нас ultralytics не используется.
- 13.5: сторонние обучающие данные — только без NC-ограничений, с описанием, ссылками и подтверждением лицензии. Сторонних данных нет.
  Данные КОЗ №2 «Сканирование» запрещены.
- Предобученные веса: по сводке 29.10 допустимы COCO, ImageNet(-21k/22k), DINOv2, Objects365, ADAF; нельзя DINOv3, SAM3, SegFormer `mit_*`,
  RF-DETR PML, любые NC. Подробно — `docs/THIRD_PARTY.md`, `docs/WEIGHTS_PROVENANCE.md`.
