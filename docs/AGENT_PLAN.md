### E10. Гистерезисный порог для объектов геофизики (только CPU)
- **Основание.** Remote Sensing 2025, 17(17):3092: на магнитке простой порог терял ямы или давал полосатый шум. Гистерезис (сильный порог для ядра, слабый для границы) плюс фильтр размера решал обе проблемы. Для карт сопротивления — тоже лучший вариант.
- **Шаги:** в `geophys.polys_from` второй порог `poly_k_low` и сборка компонент от ядер `poly_k` (`skimage.filters.apply_hysteresis_threshold`, BSD). Сетка `poly_k_low` в `scripts/geo_tune.py`. Приёмка — F1 по семьям не хуже по каждой семье, затем общий балл. ilastik (GPL) не брать.

### E11. Канал «отклонение от среднего, нормированное на σ», три масштаба (лидар, курганы)
- **Основание.** Guyot et al. 2021: лучшая из 13 визуализаций для CNN — мультимасштабное отклонение от средней высоты (e2MSTP). Открытость и SVF у нас хуже, но этот канал другой: он нормирует амплитуду между участками.
- **Шаги:** канал `dev_s/dev_m/dev_l` в `lidar.relief_channels` по образцу `lrm_xl` (сданные каналы не трогать, тест на равенство как у `lrm_xl`). Кэш, пять фолдов модели курганов, замена групп `li`/`li_coarse` по образцу `score_li_thin.py`. Компоненту RRIM не брать: по документации RVT она запатентована.
- **Стоимость:** 1,5–2 ночи.

### E12. Уточнение полигона городищ и архитектуры через SAM 2.1
- **Основание.** Из 22 спутниковых городищ, которые модель задела, внутренняя точка внутри эталона только у 15. SAM 2.1 — Apache-2.0. В работе по городищам (Geomatics 2025) он правильно очерчивал около 60 % из 1136 по точке в центре — это визуальная оценка, не метрика.

- **Стоимость:** вечер, но новая зависимость и время на 4090 нужно замерить.
