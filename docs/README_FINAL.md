## Запуск

Точка входа платформы — `metadata.json`: образ `pantum/n7q:20261024`, команда `python inference/main.py`.

```bash
python inference/main.py ПАПКА_ВЫБОРКИ work/result.geojson
python -m expds.writer check work/result.geojson
python scripts/build_submission.py
python scripts/check_submission.py dist/submission.zip
```

Образ собирается из `docker/Dockerfile` и код в себя не кладёт. Команды с томами — в [`README.md`](README.md), раздел запуска. Обучение U-Net: `python -m expds.train --cache … --out …`. Отдельного ключа с файлом конфигурации у этого модуля нет.

Архив 0,43274 этими тремя командами из `default.toml` не повторяется. Его собирает `make_candidate.py` из базы v2 и весов c5-in, которых в git нет.
