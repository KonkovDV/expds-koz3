## Предлагаемая архитектура

Локальный веб-интерфейс в Яндекс Браузере (Прил. 6 п. 2): Python 3.12 backend (FastAPI, MIT) + фронтенд MapLibre GL JS (BSD-3).
Растры — локальные тайлы через rio-tiler (BSD-3) из GeoTIFF и отмывок DEM; векторы — GeoJSON. Проект — каталог на диске (SQLite + файлы).
Обработка — очередь задач (по участкам), прогресс по SSE. Без облака: внешние подложки — опционально, при законных основаниях.
QGIS-плагин — опционально, отдельный пакет (QGIS API под GPL — держать вне основного кода).
Лицензии — проверить по п. 13.4/13.5 и внести в `docs/THIRD_PARTY.md` до начала работы.
