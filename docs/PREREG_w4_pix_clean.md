# PREREG W4 — P-clean (чистая перепись PIXGBM), до любых замеров

Записано: 29.10.2026, до обучения и до первого прогона (исполнитель bot 5, ветка `bots/w4-pix-clean`).
Спецификация: `docs/PIXGBM_SPEC_CLEANROOM.md` (bots/orch-protocol bbebfe3). Автор спецификации ≠ исполнитель.

## 0. Что сравнивается
* **A** — классическая геофизика (`expds/geophys.py` через `pipeline.geophys_feats`), `[geophys.pixgbm] enabled=false`.
* **C** — то же + `expds/pix_clean.py` (`[geophys.pixgbm] enabled=true, impl="clean", replace=true`,
  `union_name_re=""`, `model_dir="models/pixgbm/clean"`, `ground_metres=false`). Флаг G не смешивается,
  `EXPDS_GROUND_M` не задаётся.

## 1. Основной гейт (официальный, по §7–8 спецификации)
`scripts/scoreboard.py --honest 10`, global keep, A vs C, seeds 0..2, те же stack6/post; критерии §8 без изменений
(Δ ≥ +0,009; семейный бутстреп P(C>A) ≥ 0,95; ≥ 4/5 фолдов и seeds в плюс; срезы «34 новых», «без лидара»,
каждый метод не хуже −0,003; F1 finds_points и object_poly не ниже A; mock_val ≤ v2+60 с; пик ОЗУ ≤ 3 ГБ;
check_submission OK). Требует `table.pkl` и OOF стека A с ПК Елены. **На боксе их нет (`/workspace/koz3/pc_data/`
отсутствует) → гейт заблокирован; решение по умолчанию — вариант A**, пока гейт не прогнан на ПК.

## 2. Прокси-замер на боксе (заранее зафиксирован, не заменяет §1)
Классы `finds_points` и `object_poly` в трейне есть только у участков 200–217, поэтому F1 этих классов на всём
трейне = F1 на 200–217; Δglobal ≈ 0,1·(ΔF1_finds + ΔF1_poly) при неизменных прочих классах.
* **Фолды (5, фиксированы до замера):** F1={200} (Судьбищи), F2={201..207} (Семибратнее),
  F3={208,209,210,215}, F4={211,212,216}, F5={213,214,217} (Гнёздово по участкам; EtGr/TerFl есть только
  в Гнёздово, семейный фолд для них невозможен — оговорка).
* **Модели C:** для каждого фолда обучение на остальных 4 (OOF), seeds 0,1,2. Модель сдачи — на всех 18 участках, seed 0.
* **Параметры декодирования фиксированы заранее, на тесте не подбираются:** шаг сетки maggr 0,1 м, etgr 0,05 м,
  terfl — родной; NMS находок R = 1,0 м; `t_pix` = 0,5; выход object_poly — микрокруг r = 0,25 м в пике
  компоненты (`poly_mode="peak"`), мин. площадь компоненты 0,1 м²; радиус метки находки 0,4 м (кольцо 0,4–1,0 м
  игнорируется). Пороги confidence групп — `expds.metric.honest_counts` по тем же 5 фолдам (порог фолда
  подбирается без него) для A и C одинаково.
* **Метрика:** `materials/compute_metrics.py` через `expds.metric.build_curves`; GT — `expds.gt.build_gt` по 200–217.
* **Числа:** ΔF1_finds, ΔF1_poly, Δglobal-прокси (среднее по seeds), Δ по фолдам, срезы по методам
  (maggr/etgr/terfl — предсказания и GT своего метода), бутстреп по семьям (3 семьи; `paired_bootstrap_counts`,
  n=2000) и справочно — по участкам.
* **Прокси «принят»**, если Δglobal-прокси ≥ +0,009, P_fam ≥ 0,95, ≥ 4/5 фолдов в плюс, каждый метод ≥ −0,003,
  ΔF1 обоих классов ≥ 0. Даже при «принят» в сдачу без §1 не идёт. stack6/post в прокси не применяются (оговорка).
* «34 новых» и «без лидара» на боксе не считаются (нужен полный трейн) — помечаются как blocked.

## 3. Ресурсы
Бокс, `nice -n 10`, ≤ 3 тяжёлых процесса, ≤ 8 ГБ. Kaggle не используется; на CPU-аккаунты ничего не пушится.

## GEO-ORG3 — EtGr object_poly по бейзлайну организаторов 02 (HGB-режим), записано 30.10.2026 00:55 MSK до замера

Источник: ноутбук организаторов `02_baseline_etgr_anomalies` (29.10), репро координатора `orch/geo_org_repro/run_etgr.py`
(MODE=hgb: карты оценивает тот же бустинг по 16 признакам вместо ResNet18), REVIEW_ORG_GEO_BASELINES.md §6.
Модуль `expds/pix_org_et.py`, флаг `[geophys.pixgbm] org_etgr = false` (по умолчанию выкл.), модели `<model_dir>/org/org_etgr_*`.

Порт: рабочая сетка 512 px по длинной стороне; шкала jet → t; маска = контур `*_границы` ∩ расстояние до шкалы < 110;
вне маски — ближайшее валидное; z = (t − med)/MAD; кандидаты z и z − gauss(σ 20, 10 px), уровни 0,5–2,5 std, ±знак,
8-связность, площадь ≥ 30 px и ≤ 0,5 маски; 16 признаков (+5 для профилей: глубина верха/низа, карты под полигоном);
метка: попадание по правилу платформы и IoU ≥ 0,1; отдельные модели «карта»/«профиль»; порог — внутренний LOSO
по участкам обучения на сетке 0,05–0,90 по F1 платформы; NMS IoU 0,2 / 50 % меньшего; карты — разрезание пятна
на ≥ 2 вложенных детей со скором ≥ 0,5·порог. Отклонения (нет sklearn/skimage/cv2 в среде инференса):
HGB → LightGBM (lr 0,05, 300 итераций, 31 лист, min_data 20, веса balanced, ранняя остановка 10 при n > 10 000 как
у HGB auto); контур — rasterio.features.shapes (край пикселя) вместо cv2.findContours (центры); regionprops — моменты.

Замер (geo5 F3–F5, EtGr только в Гнёздово; s0; прокси `scripts/pix_clean_eval.py`, GT gt_train_v2, честные пороги):
* основной: A17 + ORG3 (EtGr object_poly заменяется ORG3) против A17;
* справочно: C-et(terfl) + ORG3, + ORG1 полигоны MagGr; сверка с эталоном организаторов
  `/workspace/koz3/org_repro/out/C_mgpoly_et.geojson` (+0,0206 у координатора).
Гейт: Δ ≥ +0,009 и P_family ≥ 0,95 (geo5), срезы ≥ −0,003, F1 класса не ниже A. Иначе — флаг остаётся выкл.
