## Жёсткие правила

1. Чужой код без лицензии, чужие веса (кроме разрешённых COCO, ImageNet, DINOv2), ultralytics, DINOv3, SAM и внешние данные без проверки лицензии — **нельзя**. Данные КОЗ №1–2 организаторы запретили прямо. Утёкшие ключи чужих бакетов не трогать никогда.
2. Пороги и постобработку по публичному баллу не двигать. Приёмка — `scripts/scoreboard.py --honest 10` по семьям, правила П1–П6 (`docs/EXPERIMENTS.md`): Δ ≥ 0,002, P(Δ>0) ≥ 0,85, LOFO и 5 раскладок > 0, тяжёлые классы и 34 новых LAS не проседают, одинаковый режим keep/drop у пары.
3. Любой шаг до порогов означает новые пороги групп по OOF после того же преобразования. Сдача и замер должны совпадать до объекта.
4. Новое в сдаче — только за ключом конфига, по умолчанию выключено. Включает бот 7 после приёмки бота 10.
5. В git не класть `dist/*.zip`, кэши, `.geojson`, веса больше 5 МБ и названия участков публичной выборки. pytest на CPU зелёный, кроме тестов, которым нужны веса не из git.
6. Таймаут обнуляет ответ. Каждый новый шаг укладывается в бюджет: `check_submission --lock` ≤ 1200 с на ПК.
