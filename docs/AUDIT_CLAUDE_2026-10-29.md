### 2.3 Почему v2 нужно загрузить сегодня

- Публичная геофизика — 1441 эталон, больше половины публичного эталона. Наш классический детектор отдал 570 объектов: подпись «мало выдачи», а не «плохие пороги». Классика давит соседние пики в радиусе 2 м. В плотных полях находок (на трейне до 173 на 1000 м², средний шаг около 1,2 м) это режет recall. У PIXGBM радиус подавления 0,75 м.
- Честный прирост PIXGBM S (+0,012) мерен на трейне, где классика и так видит 64–85 % находок. На публичной выборке узкое место другое, поэтому прирост там может быть больше. Это гипотеза. Проверить её может только площадка, и одна посылка даёт точные P/R по типам данных.
- Правило «LB отклоняет ветку только при Δ < −0,012» сохраняется. По одной посылке пороги не двигать.

### 3.5 География и правила разметки

- Курганы стоят могильниками (у соперника ближайший сосед: медиана 8,1 м на лидаре, 41,5 м на спутнике). Отсюда **множитель соседства** (§5.2).
- Правило организаторов: насыпи внутри городищ курганами не размечаются. На трейне внутри городищ 7 из 974 курганов. У соперника кандидаты внутри лидарных городищ — курганы в 2 % случаев против 45 % снаружи. Отсюда **маска городищ** (§5.1).
- Рамка сцены: метки есть только около памятника, и спутниковая сцена центрирована на нём. Framing prior у соперника на спутнике: 0,279 → 0,297. У нас его нет (P1 для бота 5/6).

### 5.1 `[post] kurgans_outside_hillforts` — правило «насыпь внутри городища»

`expds/post.py: kurgans_outside_hillforts`. Курган, чья внутренняя точка внутри выданного городища того же участка, убирается. Шаг идёт после порогов и после twins, до микрокругов. Городища вне 500–400 000 м² маской не служат: ядро-круг или ложная гигантская маска. Параметры: `min_gor_conf`, `gor_groups`, `groups`, `buffer_m`.

```bash
python scripts/oof_transform.py gormask --src КУРГАНЫ_OOF.geojson --hillforts ГОРОДИЩА_OOF.geojson \
    --taus notes/<табло>.json --out work/kur_gormask.geojson
python scripts/scoreboard.py ... --replace <группы курганов>=work/kur_gormask.geojson --honest 10
```

### 5.2 `[post] kurgan_neighbour_prior` — соседство курганов

`expds/post.py: kurgan_neighbour_prior`. Уверенность × (0,5 + 0,5·clip(n/3, 0, 2)), где n — другие места курганов того же участка в радиусе 200 м, прошедшие порог своей группы. Оба класса в одной точке считаются одним местом. Шаг идёт **до порогов**, поэтому пороги групп `li`, `li_coarse`, `li_mosaic` после него нужно подобрать заново. `pipeline.output_floors` для этих групп опускает ранний пол курганов во столько же раз: иначе множитель мог бы только понижать уверенность.
