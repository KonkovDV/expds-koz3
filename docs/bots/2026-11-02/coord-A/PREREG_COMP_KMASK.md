# PREREG COMP-KMASK — спутниковые курганы внутри выданного городища (02.11.2026, coord A)

Статус: **PREREG-черновик, замер не выполнялся.** Владелец: W3 (бот 4). CPU < 1 ч.
Идея (правило организаторов, наблюдение EN в DATA_INSIGHTS «D. Organiser hillfort rule»): ни одна спутниковая метка кургана не лежит внутри
спутниковой метки городища. Проверить на нашей разметке: доля GT kp/kt sp_or внутри GT gor sp_or (ожидаем 0).
Правило: удалить sp_dfine kp/kt в радиусе ρ·54 м (54 м — радиус медианного спутникового городища 9 206 м²) от каждой выданной v4 gor-точки sp_dfine.
Сетка nested: ρ ∈ {0.5, 0.75, 1.0}; плюс потолок по GT-полигонам (оракул) — если потолок < +0.002, не гейтить.
Гейт стандартный, заморозка всех τ, пол kp/kt −0.002. Флаг по умолчанию OFF.
