LOFO — только `nested_lofo.npz['outer']` + train-оценки canon OOF (приближение, как у автора реранкера; помечается).
- Меню стратегий порогов по классу: S0 = `sweep_groups` max (база); S1 = `sweep_groups` plateau; S2 = отдельные пороги для участков без лидара (вне `notes/las_boxes_59.json`): τ_nl по train∩без лидара, иначе τ_base (как E3 bot-2).
- Вложенный выбор (вариант N): во внешнем фолде k внутренние фолды = остальные 9 фолдов той же раскладки (чтобы OOF реранкера оставался вне фолда); на каждом внутреннем фолде все стратегии подбираются на внутреннем train и применяются к внутреннему held, счётчики складываются. Класс получает стратегию с максимальным внутренним F1 класса; S0 остаётся, если ни S1, ни S2 не СТРОГО выше S0 (при равенстве S1 и S2 берётся S1). Эталон внешнего held не участвует. Для LOFO внутренние фолды = canon-10 без held-семьи.
- Варианты: A (база), R (+реранкер arch), N (вложенные пороги, сырые уверенности), RN (реранкер + вложенные пороги). Диагностика (не решают): P1 = S1 для всех классов, P2 = S2 для всех классов (≈ E3p bot-2).
- Приёмка: П1–П5 bot-10 дословно (`/workspace/koz3_shared/EXPERIMENTS.md`). П2: `paired_bootstrap_counts`, n = 1000, семьи. П3: LOFO Δ>0 и ≥4 из 5 раскладок Δ>0. П4: взвешенная Δ povr/tselye/gor ≥ −0,0005 и new34/optical ≥ база − 0,001. Пакет RN сравнивается с A и с R.

### Дополнение к объявлению (28.10.2026 21:30 МСК, до запуска `thr_off.py`): выключение пар «модальность × класс»
- Модальность по `markup_type` группы, как в GAP.md: Or = `or`+`sp_or`, Ae = `ae`.
- Заметка: `sweep_groups` уже содержит вариант «группа выключена» (старт «none», индекс 0), т. е. τ = +∞ на уровне группы уже есть в сетке на train. Новое — **вложенный** выбор на уровне пары «класс × модальность».
- **OFFn**: кандидаты-пары povr/tselye/gor/arch × Or; povr/tselye/fort/gor/arch × Ae. Для каждой пары независимо: на внутренних фолдах (те же, что в THR) класс считается с парой и без неё (пороги остальных групп пересобираются sweep на внутреннем train); пара выключается во внешнем фолде, если внутренний F1 класса СТРОГО выше без неё. Затем пороги пересобираются на train без выключенных пар.
- Фиксированные диагностики (не решают): **EXp** — на Ae только фортификации (курганы/городища/архитектура Ae выключены) и на `or` только архитектура; **HT** — разметка `or` выключена целиком (KOZ3_SKIP_OR); **OrBroad** — povr/tselye/gor на Or (`or`+`sp_or`) выключены.
- Поверх A и поверх R; сравнение A_* против A, R_* против R. Скрипт `bot-4/work/thr/thr_off.py`, вывод `work/thr/res_off_*.json`.
