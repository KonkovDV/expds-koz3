# PIXGBM — сырые OOF-кандидаты object_poly (bot-3, для bot-6)

**Что это.** Полные полигоны компонент пиксельной карты вероятности P(пиксель внутри object_poly)
пиксельного LightGBM bot-3 (PIXGBM), **до** окончательного порога уверенности, без анкеров и без отбора
по площади (кроме ≥2 пикселей). Каждый участок предсказан моделью, обученной **без его семьи**
(leave-family-out): для Гнёздово 208–217 — модель только на MagGr Судьбищи (200) и Семибратнее (201–207),
т. е. EtGr/TerFl Гнёздово — **перенос между методами** (эталонов EtGr/TerFl вне Гнёздово нет).

**Файлы.** `<участок>_<метод>.geojson` (метод = maggr | etgr | terfl), EPSG:3857 (член `crs` указан),
только `Polygon`. `READY_<участок>` — пишется, когда все файлы участка этого прогона дописаны
(файл пишется во временный и переименовывается — частично записанных .geojson не бывает).
Порядок: сначала 212–217 etgr/terfl, затем maggr 200–212 (для 212 маркер ставится ещё раз после maggr).
`READY_ALL` — все прогоны завершены.

**Свойства объекта.**
| ключ | смысл |
|---|---|
| class | всегда `object_poly` |
| score | средняя P по компоненте (то же, что confidence кандидатов PIXGBM) |
| max_p | максимум P в компоненте |
| t_pix | пиксельный порог, на котором выделена компонента: 0.3, 0.5, 0.7 (**одна область — до трёх вложенных полигонов**, фильтруйте по t_pix) |
| area_m2 | площадь в метрах CRS карты |
| pole_x, pole_y | полюс недоступности (polylabel, tol 0.02 м), EPSG:3857 |
| region, markup_type | участок, метод |
| raster | имя карты (один участок EtGr — несколько карт/профилей; эталон каждой карты свой) |
| fold | семья, отложенная при обучении модели (= семья участка: Гнёздово / Семибратнее / Судьбищи) |
| source | `pixgbm` |

**Как получено.** `bot-3/repo` ветка `bot3-pixgbm`:
```
cd /workspace/koz3_shared/bot-3/repo
PYTHONPATH=/workspace/koz3_shared/bot-3/ehimen/pylib OMP_NUM_THREADS=2 nice -n 10 ../venv/bin/python scripts/pixgbm.py oof \
  --root /workspace/data/train-expds-3 --models /workspace/koz3_shared/bot-3/pixgbm/models \
  --out /workspace/koz3_shared/bot-3/pixgbm/oof --markups etgr,terfl --levels 0.3,0.5,0.7 --regions <участки>
```
Модели: `bot-3/pixgbm/models/<семья>/poly.txt` (обучение — `scripts/pixgbm.py train`, журнал `bot-3/pixgbm/train.log`).
Признаки, разметка и параметры — `bot-3/PIXGBM_REPORT.md`, `bot-3/pixgbm/VARIANTS_DECLARED.md`.
Компоненты: `binary_opening(P ≥ t_pix)`, 8-связность, ≥2 пикселя; сетка: EtGr 0,05 м, TerFl 0,3 м, MagGr 0,1 м.
Вне границы съёмки и в маске шума P = 0.

**Оговорки.** score не откалиброван между методами; пороги уверенности bot-3 подбирал только честно
(honest-10 фолды, группы `<метод>_pix`). Для своих порогов на Гнёздово подбирайте их, не глядя на эталон
отложенного фолда.

**Состав (проверено скриптом после записи, 2026-10-28 ~23:00 МСК).** 21 файл, все EPSG:3857, только Polygon,
все 6 обязательных ключей есть: maggr 200–212 — 32 718 полигонов; etgr 212–217 — 5 865; terfl 212 и 217 — 1 213
(у 213–216 terfl-карт нет, у 208–211 — только maggr). Журналы: `../oof_gn.log`, `../oof_mag.log`; пик RSS 560 / 673 МБ
