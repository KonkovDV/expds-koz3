**Общее для всех вариантов**

- Фолды honest-10: `/workspace/rerank/work/base_honest.pkl['folds']`.
- Калибраторы учатся только на train-семьях фолда.
- Метка калибровки — попадание объекта при исходных уверенностях.
- Калибратор = identity, если в train < 10 позитивов или < 10 негативов.
- **Калибратор фиксирован: isotonic** (IsotonicRegression, clip).
  - Обоснование из прошлого прогона: iso в режиме region наименее вреден — Δ −0.0011, P 0.36. У platt Δ −0.0042, P 0.15.
  - На no_lidar iso дал +0.0064, platt +0.0055.
- Участки «без лидара» = участки вне `notes/las_boxes_59.json`, тот же признак, что у среза no_lidar.
- WBF как в п. 5:
  - union-find по пересечению с площадью > 0 между объектами РАЗНЫХ WBF-групп внутри (участок, markup, класс);
  - уверенность = mean_g(max c) · min(N,T)/T;
  - геометрия и группа — от лучшего члена.
- Что видно в данных ДО запуска (только счётчики, без метрики):
  - на участках без лидара есть только группы sp_focal и sp_focal2 (курганы, sp_or) и одногрупповые прочие;
  - кластеров из разных групп на участках без лидара: повреждённые курганы 7 815, целые 1 358 объектов, другие классы — 0.

**Варианты**
- **(a) `nl_iso_wbf`.** На участках без лидара: iso по (класс, группа), обученный на train-объектах участков без лидара, затем WBF.
  - Для объектов участков без лидара пороги (группа, класс) подбираются `sweep_groups` по train-объектам участков без лидара, на преобразованных уверенностях.
  - Лидарные участки не меняются: сырые уверенности и пороги базы (sweep по всем train-объектам, сырые), то есть ровно как в базе.
- **(b) `all_iso_wbf_noli`.** Калибровка iso по (класс, группа) на всех train-участках, применяется везде. WBF везде.
  - Все группы markup `li` ('', li_dev, li_mosaic, li_coarse, li_mask, li_fort, gor_phys) для WBF считаются ОДНОЙ группой, поэтому между собой не сливаются никогда.
  - Пороги — обычный `sweep_groups` по всем train.
- **(c) `nl_iso`.** То же, что (a), но без WBF: только калибровка и отдельные пороги на участках без лидара.
  - Разность (a) − (c) — вклад WBF.
  - Ограничение: (c) не отделяет вклад калибровки от вклада отдельных порогов для участков без лидара.

**Правило приёмки** — bot-10, дословно из `/workspace/koz3_shared/EXPERIMENTS.md`, раздел «Правило приёмки (bot-10, 28.10.2026)»: П1–П5.

**Варианты**
- **E3n `nl_thr_nested`** — решающий вариант. Во внешнем фолде (train = семьи вне held):
  1. Базовые пороги τ_base: `sweep_groups` по всем train-объектам.
  2. Пороги τ_nl: `sweep_groups` только по train-объектам и эталону участков без лидара. Если у (группа, класс) нет τ_nl, берётся τ_base.
  3. Вложенный выбор по классам. Внутреннее разбиение train-семей: `family_folds(train, site_family, 5)`. На каждом внутреннем фолде τ_base и τ_nl подбираются на внутреннем train и применяются к внутреннему held. Счётчики складываются.
     - Класс получает τ_nl для участков без лидара, только если внутренний F1 этого класса (по всем участкам внутреннего held) СТРОГО выше, чем с τ_base.
     - Иначе для этого класса на участках без лидара остаётся τ_base.
  4. Внешний held оценивается так: лидарные участки — τ_base; участки без лидара — τ_nl для выбранных классов, τ_base для остальных.
  - Эталон и метки внешнего held во внутреннем выборе не участвуют.
- **E3p `nl_thr_plain`** — диагностика, на решение не влияет: τ_nl для всех классов, без вложенного выбора (то же, что E3n с выбором «всегда да»).

- П2: `paired_bootstrap_counts`, n = 1000.

- П4: взвешенная Δ для povr / tselye / gor ≥ −0.0005; new34 и no_lidar ≥ база − 0.001.
- Вложенный выбор делается заново в каждом внешнем фолде каждой схемы (honest-10, LOFO, раскладки).
