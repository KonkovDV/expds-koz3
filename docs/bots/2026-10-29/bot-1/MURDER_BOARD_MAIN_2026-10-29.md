```bash
# из чистого клона main, НЕ коммитить:
cp analysis/2026-10-29/bots/bot-4/runs/review/v2eb268d6/expds/geo_pixgbm.py expds/geo_pixgbm.py
echo "35e4331bbc690e7eb3b31e07cc290837ce9fd96a05c92f4c999f24eceafda35b  expds/geo_pixgbm.py" | sha256sum -c
# веса из внешнего хранилища (sha256 — models/pixgbm/all/MODELS_NOT_IN_GIT.md), затем сборка и проверка:
python scripts/build_submission.py ... && python scripts/check_submission.py <zip>
git status --porcelain   # expds/geo_pixgbm.py должен быть untracked, не в индексе
```
Байт-идентичность: эта копия = `origin/bots/bot7-candidate-v2-nomodels:expds/geo_pixgbm.py` =
`…v3-nomodels:expds/geo_pixgbm.py` (sha256 сверены сегодня). Версия с claude/audit sat-core в main не применялась.
Дополнительно стоит внести `expds/geo_pixgbm.py` в `.gitignore`, чтобы случайный `git add -A` его не закоммитил.
