## 0. Цель

К загрузке финала должна быть готова пара архивов, которую команда может защитить. Для каждого архива нужно:

- точная команда, которая пересобирает его из этого репозитория и весов по списку sha256;
- исходник, который воспроизводит сданный балл: судьи сверяют это по логам площадки (`docs/FINAL_LETTER_20261106.md`);
- ответ на вопрос «чей это код».

Новых моделей до финала не учить. Площадка публичных проб больше не принимает (`docs/RULES.md`: страница площадки закрыла загрузки 11.11). Офлайн-плюс спутника и ортофото на площадку четыре раза не перенёсся. Мерить новинку больше негде.

## 2. Запреты

1. Пороги по публичному табло не двигать. Новых порогов без OOF по семьям не ставить.
2. Не менять выход `configs/default.toml` без теста, который сверяет его до бита.
3. Не класть в чистый архив `geo_pixgbm.py`, `geo_finds_gbm.py`, `pix_legacy.py`, `models/pixgbm/*` и всё, что ловит `scripts/check_archive_clean.py`.
4. Не коммитить веса, `dist/*.zip`, кэши, выборку, разметку организаторов, ключи и токены. Ключи — только в переменных окружения.
5. Не переписывать журналы своей даты (`docs/DOCS.md`, раздел «Журналы своей даты»). Новая запись — новая строка или новый файл.
6. Не загружать на площадку и не решать за владельца. Решения раздела 3 принимает человек.
7. Не сливать и не форсить чужие ветки. Один логический шаг — один коммит.

## 4. Задачи

Порядок — по сроку. У каждой задачи есть критерий готовности. Нет критерия — задача не закрыта.

### T1. Вернуть обвязку E1_G1 в git (до 14.11, только для варианта B)

Зачем: без неё вариант B не пересобирается, а судьи сверяют исходник с баллом.

1. Взять архив `submission_pixgbm_clean_e1g1_p4_lleaves.zip` (sha256 `ed51cae4…`, Drive «2», `00_SUBMIT_NEXT_e1g1_ed51cae4`). Сверить sha256.
2. Сравнить `expds/` и `configs/` архива с `main`: `diff -ru`. Найти места, где архив вызывает `pix_e1g1` (фаза геофизики и шаги после `merge_within_markup`, список в докстринге `expds/pix_e1g1.py`).
3. Перенести только эту обвязку, за `[geophys.pixgbm] impl = "clean"`, `chain = "e1g1"`. Убрать `log.error` о неподключённой цепочке в `expds/pipeline.py`.
4. Тест: синтетический участок с картой MagGr, `chain = "e1g1"` — выход тот же, что у пайплайна архива на том же входе.

Готово, когда:

- `python scripts/check_submission.py` на пересобранном E1_G1 даёт 0 FAIL, включая `PIXGBM e1g1: pipeline.py вызывает expds/pix_e1g1.py`;
- выход пересборки на 5 участках S3 (044, 181, 210, 214, 217) равен выходу `ed51cae4` побайтно;
- `python scripts/check_archive_clean.py` на архиве — PASS.

Стоп: если побайтного совпадения нет за два подхода, остановиться и записать первую расходящуюся стадию (`scripts/golden_compare.py`). Не подгонять.

### T2. Собрать чистый финал B (после T1)

`kaggle/2026-11-05/li_cnx_in/make_candidate.py` сейчас всегда берёт артефакты v2 и `--allow-en`. Добавить режим `--clean`:

- без `scripts/v2_release_artifacts.py` и без `--allow-en`;
- база — конфиг E1_G1 через `--base-config` и `--base-sha256`;
- сборка падает, если `check_archive_clean.py` находит хоть одно нарушение.

Готово, когда:

- курганы лидара на участках с LAS совпадают с `98e0ab74` побайтно, геофизика на участках с картами совпадает с `ed51cae4`;
- `check_submission` и `check_archive_clean` — PASS;
- время на самом тяжёлом участке не больше 30 минут минус запас сторожа 3 минуты. 0,43274 шёл 5 мин 28 с на публичной выборке.

Эти два совпадения и независимость классов доказывают расчёт 0,41024 без пробы на площадке.
