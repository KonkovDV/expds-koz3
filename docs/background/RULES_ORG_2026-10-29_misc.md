# Сообщения организаторов 29.10 (переслал пользователь, 10:52–10:55 МСК)
1. После успешной попытки скачивается итоговый лог (soft recall, center dev, FP ratio, BIoU/HD95/PoLiS, P/R по типам данных, recall по размерам). На final_score не влияют. Лог v2: LB_SCORING_v2_eb268d6_0.41238.log.
2. Утверждён Технический регламент: https://upgreat.one/upload/iblock/94d/94d04946b1b4adbe0b923168d4acf81d/Tekhnicheskii_reglament_KOZ_3_Ekspeditsiya_DS.pdf
   - Лидар в валидации: на входе LAS БЕЗ готовых хиллшейдов (Прил. 1 п.4) — решение строит их само.
   - Метрика взвешенный F1, акцент на обнаружении (Прил. 4).
   - ПКК: большие данные, тепловая карта, сглаживание границ, поиск похожих, плагин QGIS (Прил. 6).
   - Разрешены стандартные компоненты NVIDIA; данные можно использовать для подготовки к финалу (13.4, 13.10.3). Исправление замечаний к ПКК ≤14 дней (3.16).
3. Лимиты результата: 100 МБ, 20 000 объектов, 3000 вершин в полигоне — ПРИМЕНЯЮТСЯ.
4. EtGr: эталон размечен в координатах каждого снимка отдельно; объекты на разных слоях (карты глубин, профили) — отдельные объекты эталона. Схлопывание слоёв снижает балл (0.655 вместо ~1.0). FP штраф ×0.5. Использовать слои комплексно можно, но полигоны — отдельно по каждому снимку.
5. Задача: один объект в пределах ОДНОГО типа данных = один полигон (дубли = FP); между типами НЕ склеивать.
6. Финал: до 10 попыток, 2 успешные. Площадка: 24 ядра, 96 ГБ, RTX 4090, /dev/shm 16 ГБ, PID ≤ 8192 вкл. потоки.
