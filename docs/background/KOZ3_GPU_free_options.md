# КОЗ №3: вычислительные ресурсы без покупки железа

> Приложение к `KOZ3_Kompleksirovanie_architecture.md`. Состояние на 12.10.2026.
> Исходные условия: локально 1 ПК с GeForce GTX 1650 (4 ГБ). Цены и условия акций меняются — перед использованием проверьте на сайте провайдера.

## 0. Вывод

Задача решается без покупки железа: бесплатные квоты команды + облачные бонусы на CPU-задачи + почасовая аренда RTX 4090 на остаток. Бюджет аренды для облегчённого v1 — **порядка 4–9 тыс. ₽** (50–100 ч 4090 по 58–87 ₽/ч; грубая оценка, объём датасета ещё неизвестен).

> **Сначала проверьте ТР.** Данные конкурса конфиденциальны; загрузка на зарубежные платформы (Kaggle, Colab) может быть запрещена. Российские облака с договором на ваше имя безопаснее, но правило то же. Вопрос можно задать организаторам: ds_analytics@upgreat.one.

### Ключевой ход — квоты команды

Каждый из пяти участников имеет свой аккаунт Kaggle и свой бонус в российских облаках.

| Ресурс | На 1 человека | На команду из 5 за 4 недели |
|---|---|---|
| Kaggle (если ~30 ч/нед) | ~120 ч T4/P100 | ~600 ч |
| Cloud.ru бонус (CPU) | 4000 ₽ | 20 000 ₽ |
| VK Cloud бонус | 5000 ₽ | 25 000 ₽ |

T4 примерно в 3–5 раз медленнее 4090 (грубая оценка), поэтому ~600 ч T4 ≈ 120–200 ч 4090 — с запасом для облегчённого v1. Несколько аккаунтов на одного человека заводить нельзя: это нарушает правила Kaggle и условия акций.

## 4. Что закрыто или не подходит

- **Amazon SageMaker Studio Lab** — закрыт для новых пользователей.
- **Google Cloud** — в пробный период GPU к ВМ подключать нельзя.
- **Modal, RunPod, Lightning AI, Paperspace** — из РФ, вероятно, нет оплаты или регистрации (не проверено по каждому).
- **Hugging Face ZeroGPU** — 5 минут в день, только для демо, не для обучения.

## 5. План на ваших ресурсах

| Шаг | Где | Что делать |
|---|---|---|
| 1 | GTX 1650 локально | код, отладка, QGIS, аудит данных, классический бейзлайн `finds.points`, лёгкая модель (ResNet18–34, тайлы 256 px) для метрики > 0 |
| 2 | Cloud.ru, CPU-ВМ на бонусах | расчёт каналов RVT по всем участкам; выгрузка готовых тайлов в float16 вместо сырых LAS |
| 3 | Kaggle, аккаунты всех участников (если ТР разрешает) | обучение облегчённого v1: одна модель на ветку, 3 фолда |
| 4 | immers.cloud или Cloud4Y, RTX 4090 | замер времени инференса, финальные прогоны, дообучение того, что не уместилось в Kaggle |
| 5 | параллельно | заявки: тест Cloud4Y; программа Yandex Cloud, если кто-то связан с вузом |

### Тонкости на GTX 1650

- Нет тензорных ядер: fp16 не ускоряет, только экономит память.
- У карт серии 16xx известны случаи NaN в половинной точности: проверяйте лосс; при проблемах — fp32.
- 4 ГБ хватает на U-Net с ResNet18/34 или EfficientNet-B0, тайлы 256 px, батч 4–8.
