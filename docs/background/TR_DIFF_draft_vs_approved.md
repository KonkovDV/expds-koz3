# Проект ТР против утверждённого ТР КОЗ №3 — что изменилось

Сравнение `tr_extract.txt` (проект) и `docs/background/TR_KOZ3_approved.txt` (утверждённый), 29.10.2026. Таблица ниже сгенерирована
скриптом по пунктам и приложениям; формулировки сверены вручную по ключевым местам.

## Главное для кода и сдачи

- **3.4 / Прил. 5:** обязательная папка `inference/` убрана — точка входа задаётся в `metadata.json` (`entry_point` — команда запуска). Наш `python inference/main.py` остаётся валидным.
- **Прил. 1:** неизвестный `class_name` пропускается, файл не отклоняется.
- **Прил. 3:** новые явные лимиты отклонения файла: > 100 МБ, > 20 000 объектов, > 50 замечаний валидатора геометрии на файл; одиночные дефекты объектов файл не отклоняют.
- **Прил. 2:** пример образа `pytorch:2.14.1-cuda13.0`; `entry_point` — команда запуска.
- **13.10.1:** копирование выборок разрешено на «устройства и вычислительную инфраструктуру под контролем Команды» с конфиденциальностью (было жёстче). Требование удаления через 14 дней после протокола (13.11.4 проекта) убрано. **13.10.3:** исключение — подготовка к Финальному конкурсу.
- **2.2.3 → 3.15–3.18:** ПКК только для призёров, до 14 дней на доработку по замечаниям (см. `docs/PKK_GAP.md`).
- **3.19:** основания дисквалификации; **9.2.3:** одно место в рейтинге на команду; **11.2.x:** порядок пересчёта при изменении метрики.
