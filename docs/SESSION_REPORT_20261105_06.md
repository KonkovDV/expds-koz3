## 2. Что сделано

**Лидар c5-in** (ConvNeXt-T, ImageNet) — `kaggle/2026-11-05/li_cnx_in/`:
- 5 фолдов на Kaggle. Гейт honest-10 поверх V3P_ctx: **R PASS**, Δ+0,0118, P 0,983, new34 +0,026. K FAIL (P 0,897).
- Прод-декодирование «как в ядре» (`expds/lidar_cnx_head.py`, `[li_cnx] decode = "head"`, `replace_li_kurgans`). Паритет с OOF ядра на 5 участках: match 1,0.
- Кандидат — `make_candidate.py`: main + артефакты v2 + конфиг v2 + `[li_cnx]`. На LB **+0,0204**.

**Лидар c12-in** (12 каналов, рецепт EN) — `kaggle/2026-11-05/li_c12_in/`:
- 12 каналов из LAS организаторов на 59 участках. Первые пять побайтно равны c5 (исправлены имена с точкой и 187). Приватный датасет `dmitrijkv/koz3-cnx-li-prep12`.
- Ядра a/b: Li-only f0–f3 0,657 / 0,491 / 0,406 / 0,247 (у c5 0,683 / 0,447 / 0,482 / 0,279). Ядро c (f4) ждёт квоту GPU.
- Правило замены c5 (Δ > 0 и P ≥ 0,9) реализовано в `gate_cnxin_ctx.py` до результатов. Прод для 12 каналов готов: `cnx_prep.py --ch 12`, тип `cnx12`; паритет подготовки побайтный.

**Ансамбль c5 + c12** — `kaggle/2026-11-05/li_ens_in/`:
- PREREG записан до результатов c12. Прод: `[li_cnx] weights_b`, одна подготовка на 12 каналов, логиты 10 сетей.
- OOF — прод-кодом (`ens_oof.py`): санити совпало с ядром c5. На Kaggle T4 — `make_ens_kernel.py`, ждёт квоту.

**Оптика: свой YOLO** — `docs/plans/OPTICS_DETECTOR_PLAN_20261105.md`, `kaggle/2026-11-06/opt_yolo/`, `expds/sp_yolo.py`:
