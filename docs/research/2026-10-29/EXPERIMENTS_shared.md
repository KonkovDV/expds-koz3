## Как пользоваться (коротко)
1. Каждый прогон = одна строка таблицы ниже. Без строки изменение не считается сделанным.
2. Честный балл = `scripts/scoreboard.py ... --honest 10` (10 фолдов по семьям, пороги подбираются на других фолдах), база и вариант — на ОДНИХ фолдах. Уровни из разных раскладок фолдов не сравнивать: уровень A гуляет от 0,2906 до 0,3184 между 5 случайными раскладками по семьям (SD 0,0107), а парная Δ — только на ±0,001 (`noise_measured.json` → `variants.A.honest10_random_seeds`, `paired.*.seed_deltas`).
3. Замеренный шум парной Δ (бутстреп по 103 семьям, 2000 выборок, изменения одной ветви размером ~0,005): SE 0,0028–0,0031; MDE (односторонний α 0,10, мощность 80 %) ≈ **0,006**; (двусторонний α 0,05) ≈ **0,008**. Δ < 0,003 одним замером не отличить от нуля.
4. Площадка (48 участков) шумнее табло: SD Δ на подвыборке 48 участков 0,004–0,007 для тех же изменений (`paired.*.lb_sim_*`), знак Δ совпадает с истинным лишь в 70–95 % случаев.

## Правило приёмки (bot-10, 28.10.2026)
Изменение ПРИНИМАЕТСЯ в сборку, только если все пункты выполнены:
- **П1.** Честная Δ (honest-10, те же фолды) ≥ **+0,002**.
- **П2.** Парный бутстреп по семьям (`paired_bootstrap_counts`, ≥1000, пороги фиксированы): **P(Δ>0) ≥ 0,85** (у табло сейчас 0,8 → при нулевом эффекте ложный приём ≈20 %; при 0,85 ≈15 %). Для сравнения: архитектура прошла с 0,897 и дала на площадке +0,0144.
- **П3.** Устойчивость: Δ по LOFO > 0 и Δ > 0 хотя бы в 4 из 5 случайных раскладок семей (`bot-10/repo/scripts/honest_bootstrap.py --seeds 5`).
- **П4.** Тяжёлые классы: взвешенная Δ (вес·ΔF1/100) по `kurgany_povrezhdennye` (30), `kurgany_tselye` (20), `gorodishcha` (15) — каждая ≥ **−0,0005**; плюс встроенное условие табло new34/optical ≥ база − 0,001.
- **П5.** Если Δ < 0,006 (ниже MDE): изменение принимается только «в пакет» — пакет принятых мелких правок перемеряется целиком против базы до посылки.
- **П6 (bot-10, 28.10 21:15 МСК). Одинаковый режим unseen.** База и вариант считаются при одном `unseen` (`drop` или `keep`, ветка `bot10-unseen-keep`). Сравнивать keep с drop нельзя: одно это даёт +0,0186 (object_poly etgr/terfl Гнёздово), см. `bot-10/REPORT3.md`.
- **П7 (bot-10, 28.10 23:35 МСК). Эффект из одной–трёх семей.**
  - Если Δ целиком дают ≤3 семьи, семейный бутстреп показывает только вероятность попадания семьи в выборку: P ≈ 1 − e^(−k), то есть 0,63 / 0,86 / 0,95 при k = 1 / 2 / 3, а нижняя граница ДИ = 0. Поэтому П2 считается **неинформативным**.
  - Такой эффект принимается только при всех условиях сразу:
    - (а) LOSO по участкам внутри семьи (параметры для участка r подбираются без r) и бутстреп по участкам с P ≥ 0,9;
    - (б) Δ ≥ 0 на всех участках, кроме не более чем одного;
    - (в) Δ приведена в drop и в keep (П6);
    - (г) в журнале стоит флаг «single-family, дисперсия занижена»;
    - (д) принимается только в пакет и только с подтверждением на LB (Δ_LB ≥ 0 при посылке пакета).
  - LOSO внутри одной семьи не заменяет П2: участки одной семьи коррелированы. Это **вторичное** доказательство.
- **Вторичная проверка (не условие приёма): устойчивость к site-scope.** Главное табло — глобальное (`bot-8/CORRECTNESS.md`). Δ того же изменения при `EXPDS_MATCH_SCOPE=site` (патч `bot-8/patch/bot8-site-scope-worktree.diff`) не должна быть отрицательной; если отрицательна или заметно меньше глобальной — изменение подозрительно (выигрыш от межучасткового сопоставления). Прошлые глобальные строки не пересматриваются.
- Площадка правило не меняет: посылка отклоняет ветвь только при Δ_LB < −0,012 (≈ −2 SD шума площадки); пороги под публичный балл не двигать.
