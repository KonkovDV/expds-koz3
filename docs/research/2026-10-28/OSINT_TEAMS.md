## (c) Технические подходы победителей (по документации ПО в реестре nti.fund — https://nti.fund/about/activity/information.php ; тексты в `osint/teams/ntipdf/*.txt`; и Хабр 1054936)
1. **Family (1 место КОЗ2)**: `inference/engine.py` — подготовка растров и LAS/LAZ → тайлинг → **ансамбль сегментации из 8 весов: 4 по «поверхностным» источникам (Li/La/Or/SpOr/Ae-подобные) + 4 по магнитометрии** → маски→полигоны → пороги → пространственный постпроцесс. По Хабру: объект принимается, если согласны **≥2 из 4 моделей**; валидация Монте-Карло (многократные случайные сплиты). КОЗ1: тайловая YOLO-seg по GeoTIFF + склейка/дедуп полигонов.
2. **mlart (2 место КОЗ2)**: ансамбль YOLO по физической модальности — `base.pt` (аэро/спутник/орто), `li.pt` (LiDAR: интенсивность + рельеф), `maggr.pt` (магнитометрия); **GSD-aware тайлинг**, фильтр дублей, своя растеризация LAS (`converter.py`).
3. **GigaFlex (3 место КОЗ2)**: 6 весов — доменные модели (спутник+орто, аэро, LiDAR-растры, магнитометрия) + **2 одноклассовых специалиста: архитектура и object_poly**; автоопределение типа данных, каналов и масштаба по разрешению; перекрывающиеся тайлы; маски→точки/полигоны; **пер-классовые пороги + геометрические ограничения**; дедуп внутри класса; EPSG:3857. По Хабру: вручную проверяли ошибки разметки.
4. **Орбис (3 место КОЗ1)**: YAML-ансамбль YOLO, `--tile-size`, `--scale-factor`, NMS+conf; рекомендуют LiDAR DEM >10–15 точек/м², орто лучше 0.5 м/px.
5. Общий знаменатель всех призёров: YOLO(11)-seg (baseline КОЗ2 тоже YOLO11seg), разделение по модальностям, отдельная магнитометрия, специалисты для редких классов, единый GSD, пороги по классам, склейка на швах.
