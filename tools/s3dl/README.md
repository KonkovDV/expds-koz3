# s3dl — загрузка публичного бакета организаторов на бокс без потерь

`s3://train-expds-3` (Selectel, `s3.ru-7`) копируется в `/workspace/data/train-expds-3` со сжатием на лету: `.las` → `.laz` (lazrs), `.tif` → тайловый GeoTIFF ZSTD (predictor 2/3). Каждый файл проверяется: метаданные и все пиксели (`pixsha`), у LAS — заголовок и точки. Ход пишется в манифест `s3_manifest.tsv`.

- `s3_dl.py` — главный цикл: s5cmd-загрузка, процессы-обработчики, пауза при нехватке диска (`S3_MINFREE_GB`), `S3_NPROC`, `S3_NDL`, `S3_ZLEVEL`.
- `plan.py` — сводка по листингу `s3_listing.jsonl` (что осталось); `bench.py` — подбор числа воркеров s5cmd; `status.sh` — состояние.

Пути (`/workspace/data/...`, `~/.local/bin/s5cmd`) рассчитаны на бокс. Ключи и `S3EP` берутся из окружения (`. ~/.koz3s3/env`), в репозитории их нет. Данные в git не идут.
