# backbone — варианты, объявленные ДО замера (29.10.2026 07:18 МСК, бот 3)

База: **S** (PIXGBM, replace=true, все группы, без R3) = кандидаты `bot-3/pixgbm/pix_lofo.geojson` (LOFO-модели `pixgbm/models/<семья>`), правило `variant_S` из `pixgbm/eval_pix.py`.
Ничего, кроме добавленных признаков, не меняется: та же выборка пикселей (воспроизводится тем же rng=default_rng(0), проверка X == pixgbm/feats),
те же 72 признака, те же параметры LightGBM (G.LGBM, 300 раундов, seed 0, веса семья×класс), t_pix 0,5, NMS 0,75 м, круг 0,5 м, полюс 0,05 м.
Обучение leave-family-out (Судьбищи / Семибратнее / Гнёздово); участок предсказывается моделью без своей семьи.

Вход бэкбона (один для обоих вариантов): 3 канала [d5, d15, z] (z — робастно нормированная карта load_map, d5/d15 — минус медианный тренд 5/15 м),
clip ±4 → x/8+0,5 → нормировка ImageNet mean/std; вне съёмки — 0. Сетка входа bb_gsd = max(gsd, 0,1 м): maggr 0,1 (как есть), etgr — среднее 2×2 (≈0,1), terfl 0,3 (как есть).
Тайлы с перекрытием, тайлы без валидных пикселей пропускаются. Признак пикселя — билинейная интерполяция карты признаков в центр пикселя.
Снижение размерности: PCA до **32** компонент, среднее и компоненты считаются **только по обучающим строкам фолда** (две семьи), для all — по всем; к 72 признакам добавляются bb00..bb31.

Варианты (только два, больше не будет):
- **B1** — ResNet18, torchvision IMAGENET1K_V1 (resnet18-f37072fd.pth, ImageNet), замороженный, выходы layer2 (128, шаг 8) + layer3 (256, шаг 16, билинейно ×2) → 384 канала на шаге 8 входной сетки; тайл 512, поле 64.
- **B2** — DINOv2 ViT-S/14 (dinov2_vits14_pretrain.pth, Meta DINOv2), замороженный, x_norm_patchtokens (384, шаг 14); тайл 518, поле 42.

Пороги: пороги уверенности групп maggr_pix/etgr_pix/terfl_pix — только вложенно внутри обучающих фолдов honest-10 (eval_pix: honest_counts → sweep_groups), никакого подбора на отложенной семье. t_pix и прочие параметры фиксированы (как в S), не подбираются.

Замер: honest-10, 4 режима (global|site × drop|keep), П1–П5 (geo_gap/evlib.criteria, бутстреп по семьям n=1000).
Решающее сравнение: **B1 vs S** и **B2 vs S** (правило S для обоих). Справочно: B1/B2 vs stack.
Приёмка: вариант принимается, только если против S выполнены П1–П4 во всех 4 режимах (как S против стека). Если оба проходят — берётся тот, у кого меньше стоимость (с учётом двух сравнений; поправки не ввожу, это консервативно, т. к. условие «во всех 4 режимах»).
Разложение по классам (finds / object_poly) — справочно, не отбор.
Контроль конвейера: модели без bb-признаков (тем же кодом) должны совпасть с pixgbm/models (проверка предсказаний на одном участке).
