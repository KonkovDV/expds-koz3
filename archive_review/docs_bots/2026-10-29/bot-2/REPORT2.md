- Классификатор моделируется **бинормально**: z ~ N(±d/2, 1), d = √2·Φ⁻¹(AUC). Метка места — подкласс совпавшего эталона, для несовпавших — Bernoulli(0.7). Правило применяется только к близнецам. Даны средние по 2 сидам, бутстреп — по сиду 0.
- Это **модель классификатора, а не реальный классификатор.**
- Формула потолка: ΔS = (30·ΔF1_повр + 20·ΔF1_цел) / ΣW, где ΣW — сумма весов классов, у которых есть эталон. Для «оракула с max conf»: ΔF1_цел = +0.0916 (0.4813→0.5729), ΔF1_повр = +0.0231 (0.3145→0.3376), откуда (30·0.0231 + 20·0.0916)/100 = +0.0253, где ΣW = 100.

**Ожидаемый прирост от п. 2 при нынешних признаках: отрицательный (около −0.007).** Перемаркировка окупается, только если на кандидатах AUC ≥ 0.9. Практический потолок — от +0.006 до +0.025.
