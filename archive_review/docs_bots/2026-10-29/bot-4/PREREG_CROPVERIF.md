# Предрегистрация CROPVERIF (bot-4, 29.10.2026 07:35 МСК) — зафиксировано ДО замера

Задача: GAP §6 п.1 — реранкер на замороженных предобученных эмбеддингах кропов, все классы, кроме городищ (их делает bot-5). Формат — как в `bot-10/PREREG_pixgbm.md`. Один вариант, без выбора по результатам.

- **Вариант E (единственный решающий).** LightGBM-реранкер на 35 признаках `/workspace/rerank/work/X2.npy` + 32 главных компоненты эмбеддинга DINOv2-B/reg (`facebook/dinov2-with-registers-base`, Apache-2.0; кроп 112 px × 0,5 м = 56 м с центром в центроиде кандидата, чтение как в `scripts/crop_verify.py::extract_crops`; признак = CLS(pooler) ‖ среднее патч-токенов без регистров, 1536 → PCA 32).
  - PCA без меток, обучается заново в каждом внешнем фолде только на строках обучающих семей.
  - Строки: только пул (`work/pool.npy`) оптических разметок (mk ∈ {sp_or, ae, or}) — ровно те, у которых есть кроп (30 688 строк, `bot-4/work/cropverif/optical_pool_cands.npz`).
  - Три модели по семействам классов: курганы (повреждённые + целые, одна модель, `cls` категориальный), архитектура, фортификация. Остальные классы и все прочие строки (лидарные курганы li*, вне пула) — исходный conf. Строки вне пула внутри реранжируемых групп получают −1 (как в `bot-10/work4/rerank/nested_lofo5.py`).
  - Параметры LightGBM — как у bot-10 nested_lofo5 (lr 0,05, leaves 31, min_data 100, ff 0,8, bagging 0,8/1, l2 1, 300 раундов, монотонность +1 по conf/logit, seed 0, 2 потока). Метка — `work/first.npy`.
  - Пороги: для внешнего фолда k оценки на обучающих семьях — внутренний 5-фолдовый OOF по семьям (seed = k), порог (группа, класс) — `sweep_groups` на обучающих участках, затем применяется к фолду k.
- **База:** A keep-all (unseen=keep), 0,333237 — воспроизведено мной из `table.pkl` (`bot-4/work/cropverif/basecheck.py`: keep 0,3332373211, drop 0,3146153227 — совпадает с `bot-10/work3/keep_vs_drop.json`). Для варианта тот же unseen=keep (П6). Scope global — основной.
- **Раскладки:** k10 (`family_folds(..., 10)`) — решающая; LOFO и random_family_folds seed 0–4 — для П3.
- **Приёмка:** П1–П6 из `/workspace/koz3_shared/EXPERIMENTS.md` без изменений (П1 Δ ≥ +0,002; П2 P ≥ 0,85 бутстреп по семьям, `paired_bootstrap_counts`, 2000; П3 LOFO Δ > 0 и ≥ 4/5 случайных раскладок; П4 взвешенная Δ по povr/tselye/gor ≥ −0,0005 и new34/optical ≥ база − 0,001; П5 Δ < 0,006 → только в пакете; П6 одинаковый unseen).
- **Обязательная проверка атрибуции** (тот же протокол, те же строки, те же раскладки): контроль X — тот же реранкер только на X2 (без эмбеддингов). Если E − X не > 0 при P ≥ 0,85 (k10), вывод: «прирост даёт реранкер, а не эмбеддинги», и эмбеддинги в сдачу НЕ предлагаются (даже если E проходит П1–П6 против базы). Контроль C (исходный conf, пороги по обучающим фолдам) — только справка.
- **Проверка честности:** PCA и LightGBM обучаются leave-family-out (внешний фолд не виден ни в PCA, ни в модели, ни в порогах); иначе — отклонить.
