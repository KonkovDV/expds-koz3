## Правка (ОДНА): SPF — слияние уверенностей двух спутниковых моделей (среднее с нулём)
Как у конкурента EXpedition (`sp_fuse.py`, bot-5/NOLIDAR.md:103: «score = среднее лучших score членов, нет = 0, радиус 8 м»), но **без склейки объектов** (дедуп вреден, bot-7/REPORT.md §3).
- Кандидаты: класс ∈ {kurgany_povrezhdennye, kurgany_tselye} И группа ∈ {sp_focal, sp_focal2}.
- Для кандидата i из группы g: o_i = максимум conf кандидатов-курганов (любого из двух классов курганов) **другой** группы (sp_focal ↔ sp_focal2) того же участка, центр которых в ≤ 8 м наземных (координаты table.pkl EPSG:3857 × cos φ); o_i = 0, если таких нет.
- Новая уверенность: conf'_i = (conf_i + o_i) / 2. Все остальные кандидаты, классы, группы, геометрия, число объектов — без изменений (объекты не добавляются и не удаляются).
- Пороги: заново `sweep_groups` (max) на train каждого внешнего фолда, как в A. Пары сопоставления — официальные из `/workspace/rerank/work/table.pkl` (точная реплика `fast.curves`), unseen=drop (П6).

## Правило решения (П1–П7 из /workspace/koz3_shared/EXPERIMENTS.md, дословно применяю)
SPF принимается, только если одновременно:
- П1: Δ canon ≥ +0,002;
- П2: P(Δ>0) ≥ 0,85 (бутстреп по семьям, n=1000);
- П3: Δ LOFO > 0 и Δ > 0 минимум в 4 из 5 раскладок seed0–4;
- П4: взвешенная Δ povr, tselye, gor каждая ≥ −0,0005; new34 и optical ≥ база − 0,001;
- П5: если Δ < 0,006 — только «в пакет»;
- П6: unseen=drop в обеих;
- П7: если ≤3 семьи дают весь Δ — П2 неинформативен, принимаю только при доп. условиях П7, иначе «не принято».
Иначе — **отклонено**. Никакой подгонки после замера.
