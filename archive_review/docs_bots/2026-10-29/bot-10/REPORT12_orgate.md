## 2. Вложенность (б) — ✓
- Внешний фолд k: модель учится на `fid_a != k`, предсказывает только `te`.
- Внутренний 5-фолд OOF строится по семьям только обучающей части: `inner = -1` для семей теста. Это проверено assert: `inner[te] == -1`, `inner[trm] >= 0`, и ни одна семья не попадает в оба множества.
- Порог: `sweep_groups` по `regions − held` (assert на пересечение пуст), held считается при этих порогах.
- Признаки участка (`r_*`, `ch_*`, `kn*`) считаются по кандидатам самого участка, без GT. Трансдуктивно внутри участка, на инференсе это доступно. Межсемейной информации нет.

## 3. Новые 22 признака (в) — ✓ с оговорками
- `feats_gate.py` использует только `table.pkl` (conf, mk, grp, cls, XY), `las_boxes_59.json` и `UTM.json`. Меток (`first.npy`/GT) в нём нет.
- Оговорка 1. `r_las` на тесте нужно вычислять тем же правилом: есть ли LAS на входе участка. Если на сабмите он будет всегда 0, гейт поведёт себя как G_noLAS без LAS-сигнала.
- Оговорка 2. lat/lon (`UTM.json`): если публичные участки лежат вне географии трейна, это риск. Без гео (G_noGeo, `bot-6/.../res_v1/k10.log`) dR всего +0,001792 — разница −0,00014. Это довод за упрощение, но вариант post-hoc, и семян по нему нет.
- Оговорка 3. Гейт обучен на текущем стеке кандидатов. Любой пункт, меняющий кандидатов arkhitektury, требует переобучить гейт и перемерить пакет: эффекты не аддитивны.

## 4. Отбор (г): G против G_noLAS
