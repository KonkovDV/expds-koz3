## 5. Есть ли путь к скачку на LB без новых моделей?
- **Оракул-реранкер 0.658 vs идеальные пороги 0.367** — это офлайн-потолок при идеальном ранжировании наших же кандидатов. Без нового сигнала ранжирования он недостижим: все обученные реранкеры (V5/V5x/V6c, WS-RR1/RR2) дали ≤ 0 в сумме. Единственный подтверждённый сигнал — V5x на лидаре new34 +0.0224 → его можно брать **только на Li/La-слоях с пересвипом τ**, и только вместе с новыми признаками (dino-emb, CI2-1 cloudfeat), иначе это повтор отклонённого WS-RR1.
- **Пороги (0.314 → 0.367, +0.052 офлайн)**: break-even τ per class×type + floor top-k (REVIEW_SOTA #3) + M_rp — CPU, без моделей, оценка +0.005…+0.02.
- **Главный кандидат на «скачок» без моделей — уже готовый ORG3 (+0.0232 офлайн, геофизика; PASS ночью 30.10, т.е. после сдачи v2 29.10 — в LB 0.4124 по датам не входил, C подтвердить по архиву 26ad1ba).** Исторически геофизические изменения усиливались офлайн→LB: v2 +0.011/+0.014 → LB +0.064 (×4.6–5.9), arch +0.0036 → +0.0144 (×4) (REVIEW_SOTA §2.3). Расчёт-гипотеза: при усилении ×2…×4 ORG3+M_rp дают LB **+0.05…+0.11 → 0.46…0.52**. Это НЕ прогноз (шум LB ±0.034, другая природа рычага) — проверять gate #12 «публичный состав» до сдачи и одной LB-сдачей v3a-минимум.
- **Вывод:** без новых моделей реалистичный потолок публичного LB ≈ 0.46–0.52 (v3a + пороги + xlayer). До 0.61 нужно ещё +0.09…+0.15 — это только ранжирование (реранкер с гейтом по модальности, если ляжет +0.01–0.04) плюс удача с составом. Честная вероятность ≥0.61 остаётся низкой (MASTER_PLAN: <3 %); цель > 0.5 — реалистична.
