### 1.3. Приёмы EN, в которых он нас обходит (спецификации, без кода)
**Спутник (главный разрыв):**
- S1. Фьюжн 5–6 детекторов: несколько D-FINE-L (разные сиды/рецепты, без denoising), RT-DETRv2-R50, heatmap U-Net центров.
  Равные веса, **порог 0.25 один на все классы** (выбран во всех фолдах), кластеризация 8 м, дедуп 3 м. Каждый член добавлял ≤ +0.008 honest.
- S2. Гейт городищ по сцене: классификатор «на маленьком скриншоте есть городище». Если p ≥ g, ставится центр сцены с conf = p; детекторные городища снимаются при p < g (+0.03 honest на спутнике).
- S3. Framing prior: разметка есть только у памятника, точность падает от центра к углам (0.38 → 0.05) → множитель по расстоянию от центра сцены (x 0.5, t2 0.35).
- S4. Хедж повреждённый/целый 0.4: при неуверенном классе кургана выдаётся второй круг другого класса.
- S5. Архитектура на спутнике: порог 0.15 (у нас 0.287).

**Лидар:**
- L1. U-Net ConvNeXt-T, 9 каналов рельефа из LAS, heatmap курганов + маски классов; курганы из пиков, городища/форты — компоненты маски.
- L2. **Dual-эмиссия:** пик кургана выдаётся обоими классами, если второй класс ≥ 0.05. Honest 0.5223→0.5319, с классификатором морфометрии 0.5349.
- L3. Ансамбль 4 моделей: 2 сида + copy-paste насыпей + «открытость»; мягкий бленд, порог 0.15. 0.534→0.577 honest.
- L4. d8 TTA на полных тайлах (у нас TTA лидара отвергнут, но на другой сети).
- L5. Баланс участков в обучении (+0.012–0.016); соседский приор (+0.0104).
- L6. Земля: облака без класса 2 → без PMF (PMF срезает насыпи); у нас похожий аудит CI2-3.

**Геофизика:** finds — физические кандидаты + LightGBM (0.72); objects — 0.5·CNN + 0.5·GBM; MagGr thr 0.75; EtGr — каждый слой отдельно (у нас уже есть ORG3 +0.0232).
**Ae:** только FCOS-форты thr 0.4 (у нас маска фортов с порогом 0.998). Курганы на Ae не обобщаются ни у кого.
**Or:** спутниковый D-FINE на орто, ресемпл 0.5 м, только архитектура, conf ≥ 0.45.
**Методика:** симулятор валидации (выборки «как public» из трейна), приёмка «leave-largest-contribution-out» (k* ≥ 5, P ≥ 0.9). У нас аналог — honest-10 + бутстреп.
