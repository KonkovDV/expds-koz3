# KOZ3 — общий бриф для ботов (от бота 1, координатор)
Цель Элены: официальный балл КОЗ-3 выше 0.61. Лучший официальный сейчас 0.41238 (29.10, v2 eb268d6). Честная офлайн-база honest-10: A=0.314615.
Репо: https://github.com/KonkovDV/expds-koz3 (приватное). Ветки v3/v4: bots/bot7-candidate-v3-nomodels и т.д.
Метрика: форма контура НЕ влияет на балл. Попадание = покрытие (пересечение/меньшая площадь) >= 0.5 и внутренняя точка внутри эталона. F1 = 2TP/(2TP+0.5FP+FN). Веса: курганы повр. 30, целые 20, городища 15, архитектура/object_poly/finds 10, фортификации 5. Рычаг: полнота и верный класс.
Обязательно прочитать: /workspace/koz3/orch/PROTOCOL.md, /workspace/koz3/orch/LEASES.json. Контекст с ПК Элены: /workspace/koz3/local_ctx/ (официальные логи, планы, материалы организаторов). Мои рабочие файлы: /workspace/koz3/ (cpu/, out/, pull/).
Kaggle: CLI ~/.local/bin/kaggle, запуск через /workspace/koz3/orch/pool_kaggle.sh (токены читаются в момент запуска, нигде не печатать и не коммитить). GPU/TPU только elenakonkova и dmitrijkv; usertest1234, aaaa0000004, aaaadg4gg4g4g — только CPU.
Правила:
1. Перед любым kaggle push — аренда слота в LEASES.json; после — снять. Чужие RUNNING/QUEUED ядра не трогать, не удалять. Префикс своих ядер koz3-wN-.
2. Свой статус — только в /workspace/koz3/orch/bot-WN/STATUS.md (обновлять на каждой вехе). docs/STATUS.md и решение о включении — только W4.
3. Варианты опыта записать в PREREG до замера. Изменения только за флагом, по умолчанию выкл.
4. Гейт: honest-10 той же compute_metrics.py, прирост >= 0.003 и P(A>B) >= 0.9, без просадки на новых LAS и участках без лидара.
5. В main не пушить. Посылки на LB не делать — их делает только Элена.
6. Пока Элена не согласилась: не загружать данные в датасеты CPU-аккаунтов и не расшаривать датасеты между аккаунтами.
7. ПК Элены может быть офлайн; на её компьютере ничего не менять.
