# Экспедиция DS. Комплексирование (КОЗ №3), правила (от Elena, 29.10.2026)
- Квалификационный этап: 12.10–14.11. Elena: финал 11.11. Финальный этап: до 10 попыток всего, до 2 успешных всего.
- Квалификация: до 10 попыток в сутки, до 3 успешных в сутки.
- Сабмит: ZIP с исходным кодом, metadata.json в корне (поле image = Docker-образ), архив ≤2 ГБ, образ ≤50 ГБ (compressed×3).
- Контейнер: 30 мин, i9-14900KS (24 ядра), 96 ГБ RAM, RTX 4090 24 ГБ, /dev/shm 16 ГБ, PID ≤8192 (вместе с потоками).
- Результат: ≤100 МБ, ≤20000 объектов, ≤3000 вершин в полигоне.
- Внутри одного типа данных один объект = один полигон (дубли = FP); между типами данных НЕ склеивать (метрика считает отдельно по типу).
- Данные: Я.Диск https://disk.yandex.ru/d/fLYrcMEDnv9_Mw ; S3 s3.ru-7.storage.selcloud.ru:443 bucket train-expds-3 (ключи организаторов см. сообщение Elena 29.10; на GH не коммитить).
- Апдейты датасета: 05.10 017 Li_ch; 11.10 008 Or; 12.10 091 разметка; 14.10 папки 200-217 геофизика; 15.10 LAS 024/033/190, UTM 201-206, MagGr 200; 20.10 101/102 La_точки + Li_карты.
- Бейзлайн: YOLO-seg по хиллшейдам (LAS→DEM 0.1 м→хиллшейды→тайлы 1024, conf 0.25→EPSG:3857→дедуп+фильтр площади).

- Консультация №1 (презентация, docs_org/, прочитано 30.10): финальные испытания с загрузкой финального кода — **17–19 ноября** (не 11.11); лимит попыток финала фиксирован на весь период; если команда не загрузит финал сама — автоматически берутся **2 решения с лучшей публичной метрикой** квалификации. Для допуска к финалу max публичная метрика > 0. Закрытая выборка не пересекается с публичной. Лимиты попыток обновляются в 00:00 МСК.
- Образ — свой, выгружается на DockerHub **публично**. Шаблон структуры: `docs/README.md`, `docs/ai_declaration.md`, `inference/main.py` — единственная точка запуска, `metadata.json` в корне.
- Метрика (изменения к КОЗ2): объект засчитывается по частичному перекрытию ИЛИ попаданию центра; точки — по расстоянию; точность контура на балл не влияет (справочно); FP стоит вполовину («лучше показать лишнее»). Не меняются: формула, веса классов, «один эталон — одно предсказание», состав классов.
- Классы геофизики (размеры в «м», вероятно м²): MagGr finds.points r 0,1–1 м; object.poly 1–30; structure.poly 2–400. EtGr object.poly 0,3–10/12, глубже 2 м — геология. TerFl object.poly 0,3–10; structure.poly 1–50. Папки: 08_*_EtGr_карты и 08_*_EtGr_профили (оба с номером 08). Георадар заявлен, но в датасете нет.
- Объём: лидар/оптика 880 участков (курганы 7328, городища 1462, фортификация 762, архитектура 666); геофизика 142 участка (MagGr 5134, EtGr 1000, TerFl 330 объектов). Датасет КОЗ1 не использовать, КОЗ2 синхронизирован и будет удалён.
- Победители (1–2 места) в течение 30 дней после финала сдают алгоритм с UI и инструкциями (ПКК: QGIS-плагин, тайлинг, продолжение после ошибки, тепловая карта ниже порога и т.д.). Экспертиза первых 3 заочно, ответ ≤3 дней, затем очная верификация.
