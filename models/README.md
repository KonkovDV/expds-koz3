# models/

Сюда кладутся веса, на которые указывает `configs/default.toml`. В архив платформы `scripts/build_submission.py` берёт только такие пути.

Секция `[models]`:

- `li_r18_hard2.pt` — курганы лидара;
- `li_gor_mask_r18.pt` — маска городищ;
- `li_fort_mask_r18.pt` — маска фортификаций;
- `li_dev_r18.pt` — канал σ;
- `spor_gor_r18.pt` — городища спутника;
- `spor_focal_r18.pt` — курганы спутника;
- `surf_arch_r18.pt` — архитектура и спутника, и ортофото;
- `spor_focal_wide_r18.pt` — окно 256 м на участке без LAS;
- `ae_fort_mask_r18.pt` — фортификации аэрофото.

Рядом, но не в `[models]`: `kurgan_lgbm.txt` — запасной оценщик (`[candidates]`), `sp_crop.pt` — проверка кропа (`[verify] enabled = true`).

`spor_arch_r18.pt` в конфиге не стоит. Ранние `li_r18.pt` и `ae_r18.pt` тоже. Сеть находок на картах магниторазведки в секции закомментирована. Веса ConvNeXt c5-in в git не лежат: архив 0,43274 собирается отдельно, а в этом файле `[li_cnx] enabled = false`.

Репозиторий приватный. Эти файлы — производные конкурсных данных.
