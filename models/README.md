# models — веса решения

Веса обучены на данных конкурса и в git не хранятся: они лежат в архиве финальной версии (178 файлов,
sha256 `171bed30…7b252`). Чтобы собрать архив из клона репозитория:

1. Распакуйте из архива финальной версии каталог `models/` в корень репозитория и сверьте контрольные суммы:

   ```bash
   sha256sum -c models/MANIFEST.sha256
   ```

2. Положите сторонние файлы: `vendor/` (lleaves, llvmlite) и колесо RVT. Их можно распаковать из того же архива
   или скачать с PyPI со сверкой sha256:

   ```bash
   python scripts/fetch_thirdparty.py
   ```

3. Проверьте, что все 178 файлов архива на месте и совпадают со сданными:

   ```bash
   python scripts/verify_archive.py --local
   ```

После этого `python scripts/build_submission.py` даёт сданный архив до байта (`tests/test_final_config.py`).

Параметры обучения каждой сети записаны в её чекпойнте; у сетей ConvNeXt там же — контракт входа и выхода и
sha256 кода подготовки каналов. Как обучалась каждая модель — `docs/README.md`, раздел «Воспроизведение
решения»; сети ConvNeXt-лидара — `training/lidar_convnext/README.md`. Перед запуском на новой машине сверьте
веса с манифестом: `python scripts/verify_archive.py --local`.
